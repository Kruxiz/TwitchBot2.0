First-Time Setup

To get started, you'll need to create developer applications for both Twitch and Spotify to obtain the necessary Client IDs and Client Secrets.

Follow these links to create the applications:

  • Twitch Developer Console
  • Spotify Developer Dashboard

If you had previously set up an older version of the bot, you can copy your Client IDs and Client Secrets from the Windows Environment Variables.

You can then simply update your redirect URIs with the updated values below:

Register these redirect URIs in the provider dashboards:

  • Twitch: {{TWITCH_REDIRECT_URI}}
  • Spotify: {{SPOTIFY_REDIRECT_URI}}

After obtaining the Client IDs and Client Secrets, enter them below to complete the setup:
